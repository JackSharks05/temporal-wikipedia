# Simple Time Diff Indexer (still wip)

Builds a `diff:year:word` index over all stored Wikipedia articles by diffing consecutive year-end snapshots.

## Usage

```bash
node indexer/temporalDiff.js --port 9000 --gid all
```

## Output

For each word that changed between year-end snapshots, writes a `diff:<year>:<word>` key to the store:

```json
{
  "totalAdded": 12,
  "totalRemoved": 3,
  "articleCount": 5,
  "articlesAdded": 4,
  "articlesRemoved": 2
}
```

# jdh implementation

`word -> [{pageId, startTime, endTime}]`

if page is still current then `endTime = null`

`startTime <= T < endTime`
